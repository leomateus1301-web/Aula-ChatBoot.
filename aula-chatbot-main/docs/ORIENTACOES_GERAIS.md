# Orientações gerais para os alunos

- Cada aluno deve usar sua própria conta GitHub e seu próprio repositório de trabalho.
- O repositório `aula-chatbot` é a coleção de exemplos fornecida pelo professor.
- Cada projeto tem seu próprio `README.md`, lista de dependências e documentação.
- Não compartilhe senhas, tokens de acesso nem dados pessoais.
- Antes de iniciar um projeto, confira o diretório atual com `pwd` e leia as instruções específicas.
- Para encerrar uma aplicação, pressione `Ctrl+C` no terminal. Depois, pare o Codespace quando terminar para economizar a cota.
